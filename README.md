# 台灣監理站車牌競標即時看板 V2.5

背景定時掃描全國監理站的「競標中號牌查詢」，把每一次抓到的價格存成出價歷史，
用網頁看板、Email 提醒、Discord bot 三種方式呈現。

## 功能

- **即時看板**：全國競標中的號牌，可依車種、地區、監理站、號碼、號碼型態
  （鐵支／豹子／順子／對子／回文）篩選，依截止時間或出價排序，快截止的高亮。
  配色可切自動／淺色／深色
- **出價歷史查詢**：每面號牌的出價走勢圖、決標紀錄、每日決標行情統計。
  頁面跟著背景掃描的節奏自己更新，不用手動重整
- **Email 提醒**：兩種都是截止前幾分鐘寄信，門檻每個帳號自己設
  - 追蹤清單——收藏想標的那面號牌，只提醒那一面
  - 車種訂閱——選幾個車種，全國符合的號牌都提醒
- **Discord bot**：`/查詢`、`/歷史`、`/急件`、`/狀態` 等指令，車種和監理站可
  從選單直接點，出價趨勢會直接畫成圖片貼出來
- **多人帳號**：第一個帳號是管理者，其他人註冊後收驗證信、點連結就開通

## 安裝與啟動

```
pip install -r requirements.txt
python webapp.py
```

然後用瀏覽器開 http://127.0.0.1:5000

第一次啟動會自動導向 `/setup` 建立管理者帳號。掃描間隔（預設 10 分鐘）、提醒
門檻、Email 與 Discord 的設定都在網頁的「設定」頁填，不需要手動編輯設定檔。

長期常駐執行（背景啟動、停止、重啟、看 log）請見 [OPERATIONS.md](OPERATIONS.md)。

## 來源網站給得到什麼

這些限制決定了資料能做到什麼，fork 之前先知道比較好：

- 只公布「目前出價」和「出價次數」兩個當下的數字，沒有出價明細。**兩次掃描
  之間發生的出價，金額永遠拿不到**——間隔設 3 分鐘實測仍有約 44% 的出價次數
  是跳過的，熱門號碼常在截止前連喊好幾口。所以趨勢圖的橫軸是出價次數而不是
  時間，中間漏掉的那幾次會拉開間距，看得出來哪一段沒抓到
- 截止前有人出價就往後延 3 分鐘（防搶標），同一面號牌一天被延好幾次很常見
- 維護時段會整批回傳 0 筆而且 HTTP 不報錯。判定決標時會先按住幾輪、抓取失敗
  的站不判，避免把維護誤記成全部結標——決標紀錄是寫進資料庫、事後要人工清的

## 設定檔

`config.json` 會在第一次啟動時自動產生（含隨機的 session 簽章金鑰），
不需要手動建立。[config.example.json](config.example.json) 只是讓你知道有哪些欄位可以調。

以下檔案含有機密或個人資料，**已列在 .gitignore，不會進版控**：

| 檔案 | 內容 |
|---|---|
| `config.json` | Email 應用程式密碼、Discord bot token、session 簽章金鑰 |
| `accounts.json` | 所有使用者的帳號與密碼雜湊（由 `/setup` 與註冊流程自動維護，不要手寫） |
| `data/` | 掃描快取、出價歷史資料庫、個人追蹤清單 |
| `logs/` | 執行紀錄（含登入失敗的來源 IP） |

自己 fork 或重新部署時，這幾個檔案都會在第一次執行時自動重新產生。
