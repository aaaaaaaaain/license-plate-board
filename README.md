# 台灣監理站車牌競標即時看板 V1.0

背景每 10 分鐘掃描全國監理站的「競標中號牌查詢」，網頁即時顯示競標狀況、
記錄每個號碼的出價走勢與決標結果，快截止時可寄 Email 或用 Discord 提醒。

## 功能

- **即時看板**：全國監理站競標中號牌，可依車種／地區／監理站／號碼篩選與排序，快截止的號牌高亮
- **出價歷史查詢**：每個號碼的出價走勢圖、決標紀錄、每日決標行情統計
- **個人追蹤清單**：登入後收藏想追的號碼，截止前寄信提醒（每個帳號有自己的提醒門檻）
- **Discord bot**：用指令查詢競標中號牌與出價歷史
- **多人帳號**：第一個帳號為管理者，其他人註冊後需管理者核准

## 安裝與啟動

```
pip install -r requirements.txt
python webapp.py
```

然後用瀏覽器開 http://127.0.0.1:5000

第一次啟動會自動導向 `/setup` 建立管理者帳號。Email 與 Discord 的設定在網頁的
「設定」頁填寫，不需要手動編輯設定檔。

長期常駐執行（背景啟動、停止、重啟、看 log）請見 [OPERATIONS.md](OPERATIONS.md)。

## 設定檔

`config.json` 會在第一次啟動時自動產生（含隨機的 session 簽章金鑰），
不需要手動建立。[config.example.json](config.example.json) 只是讓你知道有哪些欄位可以調。

以下檔案含有機密或個人資料，**已列在 .gitignore，不會進版控**：

| 檔案 | 內容 |
|---|---|
| `config.json` | Email 應用程式密碼、Discord bot token、session 簽章金鑰 |
| `accounts.json` | 所有使用者的帳號與密碼雜湊（由 `/setup` 與註冊流程自動維護，不要手寫） |
| `data/` | 掃描快取、出價歷史資料庫、個人追蹤清單 |
| `logs/` | 執行紀錄（含登入失敗的來源 IP） |

自己 fork 或重新部署時，這幾個檔案都會在第一次執行時自動重新產生。

## 需求

Python 3.10+，套件見 [requirements.txt](requirements.txt)。
